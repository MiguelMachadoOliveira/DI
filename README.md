# DI
Projeto final de DI

Primeiro passo foi escolher o tema do site, que foi a equipe Ferrari de fórmula 1 resumindo um pouco da história, pilotos, carros e títulos ao longo dos anos. O segundo passo foi ver quais pilotos e carros para separar as imagens que seriam utilizadas em uma pasta separada. O terceiro passo foi fazer a parte do HTML de cada página já separando por classes para facilitar o a criação posterior do CSS. O quarto foi pensar em como queria que fosse
o site após o CSS utilizando o Canva fiz um rascunho de como queria e depois programei o CSS. E por último crie um Java Script para poder usar as opções de acessibilidade como tema claro e escuro e aumentar ou diminuir a fonte, junto da parte de cadastro.
